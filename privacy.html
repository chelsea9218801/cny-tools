プライバシーポリシー

本アプリ「CHELSEA APP（店舗業務ツール）」（以下「本アプリ」）は、CHELSEA NEW YORKの店舗スタッフが商品マスタを参照し、価格リストなどの帳票を作成するための社内向けツールです。本ポリシーは、本アプリがGoogleのユーザーデータをどのように扱うかを説明します。

1. アクセスするGoogleユーザーデータ

本アプリは、利用者がGoogleアカウントでログインして許可した場合に限り、Google Sheets APIのスコープ https://www.googleapis.com/auth/spreadsheets.readonly により、あらかじめ指定した1つのGoogleスプレッドシート（商品マスタ：品番、JAN、カラー、サイズ、価格など）の内容だけを読み取ります。他のファイル、メール、連絡先、利用者のプロフィール情報（氏名・メールアドレスなど）にはアクセスしません。スプレッドシートへの書き込み・変更・削除も行いません。

2. データの利用目的

読み取った商品マスタは、帳票へのJANコード・カラー名・サイズ名等の付与と、画面表示・印刷出力という、利用者向けの機能を提供するためだけに使用します。広告、プロファイリング、AI/機械学習モデルの学習など、その他の目的には使用しません。

3. データの共有・第三者提供

本アプリは運営者のサーバーを持たない静的なWebサイトであり、読み取ったデータを運営者のサーバーや第三者へ送信・共有・販売することはありません。データは利用者のブラウザとGoogleのAPIの間でのみやり取りされます。

4. データの保護

通信はすべてHTTPS（暗号化通信）で行われます。ログインにより取得したアクセストークンはブラウザのメモリ上にのみ保持し、ページを閉じると破棄されます（トークンを保存・送信しません）。スプレッドシート自体へのアクセスは、Googleのドライブの共有権限により、運営者が許可したアカウントに限定されています。

5. データの保存期間と削除

読み取った商品マスタは、画面表示を速くするため、利用者自身の端末のブラウザ内（IndexedDB・ローカルストレージ）にのみ保存されます。運営者側には保存されません。ブラウザの「サイトデータの削除」を行うことで、いつでも端末内のデータを削除できます。また、Googleアカウントの権限設定から本アプリへのアクセス許可をいつでも取り消せます。

6. Limited Use（限定的使用）について

CHELSEA APPが、Google APIから受け取った情報を他のアプリに使用・転送する場合も、Google API Services User Data Policy（限定的使用の要件を含む）を遵守します。

Privacy Policy (English)

"CHELSEA APP" (the "App") is an internal tool for CHELSEA NEW YORK retail store staff to reference our product master data and produce reports such as price lists. This policy explains how the App handles Google user data.

1. Google user data accessed

Only after a user signs in with their Google account and grants permission, the App uses the Google Sheets API scope https://www.googleapis.com/auth/spreadsheets.readonly to read the contents of one specific, pre-designated Google Sheet (our product master: item numbers, JAN codes, colors, sizes, prices). The App does not access any other file, email, contact, or the user's profile information (name, email address, etc.). It never writes to, modifies, or deletes any spreadsheet.

2. How the data is used

The data is used solely to provide user-facing features: adding JAN codes, color names and size names to reports, and displaying/printing them. It is not used for advertising, profiling, or training any AI/ML model.

3. Sharing and transfer

The App is a static website with no server operated by us. We do not transmit, share, or sell the data to our servers or to any third party. Data flows only between the user's browser and Google's APIs.

4. Data protection

All communication uses HTTPS. The OAuth access token is kept only in the browser's memory and is discarded when the page is closed; it is never stored or transmitted elsewhere. Access to the spreadsheet itself is restricted by Google Drive sharing permissions to accounts we have authorized.

5. Retention and deletion

To speed up the display, the retrieved master data is cached only in the user's own browser (IndexedDB / local storage). It is not stored on any server of ours. Users can delete it at any time by clearing the site data in their browser, and can revoke the App's access at any time at Google Account permissions.

6. Limited Use

CHELSEA APP's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
